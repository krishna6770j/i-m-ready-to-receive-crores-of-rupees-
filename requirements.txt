# IMPORTANT -- the `asyncio` backport:
# fyers-apiv3 declares a dependency on the PyPI package named `asyncio`
# (version 3.4.3, a 2015-era backport of the standard library module). It
# installs a directory literally called `asyncio` into site-packages, which can
# shadow the stdlib module of the same name. On this machine stdlib still won
# on sys.path, but the situation is fragile and the backport cannot run on
# Python 3.12 at all. It is uninstalled after install; the SDK (including both
# websocket modules) was verified to import and work without it.
# Full transitive versions are recorded in requirements.lock.txt.
